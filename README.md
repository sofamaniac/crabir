# Crabir

An open source replacement for Boost for Reddit.

## Features

- Multi account support
- Browse communities
- Interact with posts
- Theme customization
- View customization
- Go to a random community
- View comments
- Write comments
- Create posts
- Edit posts
- See inbox
- ...
